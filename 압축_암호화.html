1. 디지털 데이터

컴퓨터는 현실 세계의 정보를 그대로 이해하는 것이 아니라 정보를 디지털 데이터로 변환하여 처리한다.

핵심: 현실의 연속적인 정보를 컴퓨터가 처리할 수 있는 디지털 형태로 바꾸는 과정이 중요하다.

대표적인 대상은 사진, 소리, 영상, 문자 등이다.

2. 표본화

표본화(Sampling)는 연속적인 아날로그 신호를 일정한 시간 간격으로 측정하여 표본을 얻는 과정이다.

예시

마이크가 사람의 목소리를 받아들인다고 생각해 보자.

실제 소리는 시간에 따라 연속적으로 변하지만, 컴퓨터는 모든 순간의 값을 무한히 저장할 수 없다.

따라서 일정한 간격마다 소리의 크기를 측정한다.

표본화 = 시간축에서 얼마나 자주 측정하는가

표본화 주파수

1초 동안 몇 번 표본을 얻는지를 표본화 주파수라고 한다.

단위는 Hz를 사용한다.

예를 들어 44,100 Hz라면 1초에 44,100번 측정한다는 의미이다.

시험 포인트:
표본화 → 신호를 일정한 시간 간격으로 측정

3. 양자화

표본화한 값은 여전히 연속적인 값일 수 있다.

컴퓨터에서 저장하려면 이를 일정한 단계의 값으로 나누어 표현해야 한다.

이 과정을 양자화(Quantization)라고 한다.

양자화 = 측정한 값을 정해진 단계의 값으로 바꾸는 것

쉽게 구분

과정 무엇을 하는가?
표본화 언제 측정할 것인가?
양자화 측정한 값을 어떤 단계로 표현할 것인가?
부호화 그 값을 어떤 디지털 코드로 나타낼 것인가?
암기:
표본화 → 시간
양자화 → 값의 단계
부호화 → 코드

4. 부호화

양자화된 값을 컴퓨터가 처리할 수 있는 디지털 코드로 표현하는 것을 부호화(Encoding)라고 한다.

컴퓨터에서는 대표적으로 0과 1을 이용한다.

표본화 → 양자화 → 부호화

이 세 과정을 연결해서 기억하면 된다.

아날로그 신호 ↓ 표본화 ↓ 양자화 ↓ 부호화 ↓ 디지털 데이터

5. 손실 압축

손실 압축은 압축 과정에서 일부 데이터를 제거하여 파일 크기를 줄이는 방법이다.

압축을 풀어도 원본과 완전히 동일하지 않을 수 있다.

손실 압축
일부 정보 제거 → 파일 크기 감소 → 원본과 완전히 같지 않을 수 있음

예시

  • JPEG 이미지
  • MP3 음악
  • AAC 음악
시험에서 자주 묻는 것:
"압축 해제 후 원본과 완전히 동일한가?"

손실 압축 → 아니오

6. 무손실 압축

무손실 압축은 데이터를 압축하더라도 압축을 해제하면 원래 데이터를 완전히 복원할 수 있는 방법이다.

무손실 압축
정보를 정확하게 보존 → 압축 해제 시 원본 복원 가능

대표적인 예

  • PNG
  • GIF
  • FLAC

문서나 프로그램 파일처럼 데이터가 조금이라도 달라지면 문제가 되는 경우 무손실 압축이 중요하다.

7. 사전 기반 압축

사전 기반 압축은 데이터에서 반복되는 문자열이나 패턴을 찾아 사전에 저장하고, 반복되는 부분을 짧은 표현으로 바꾸는 방식이다.

간단한 예

원본: ABCABCABCABCABCABC 사전: 1 = ABC 압축 데이터: 111111

실제로는 훨씬 복잡한 방식으로 동작하지만 핵심 아이디어는 반복되는 패턴을 짧게 표현하는 것이다.

사전 기반 압축 핵심:
반복되는 데이터 → 사전에 등록 → 짧은 코드로 표현

관련 개념

LZ 계열 알고리즘 등에서 이러한 아이디어가 사용된다.

8. 압축률

압축이 얼마나 잘 되었는지를 나타내는 대표적인 값이 압축률이다.

기본적인 계산

압축률(%) = 압축 후 크기 ÷ 압축 전 크기 × 100

예시

압축 전 파일 크기가 100MB이고 압축 후 40MB가 되었다고 하자.

40 ÷ 100 × 100 = 40%

따라서 압축 후 크기는 원본의 40%이다.

압축으로 얼마나 줄었는가?

감소율(%) = (원본 크기 - 압축 후 크기) ÷ 원본 크기 × 100

위 예시에서는

(100 - 40) ÷ 100 × 100 = 60%

즉 60% 감소했다.

주의:
"압축률 40%"와 "60% 줄었다"는 같은 상황을 다른 방식으로 표현한 것이다.

9. 이미지 파일 형식

형식 특징 압축
BMP 압축을 거의 사용하지 않는 비트맵 이미지 형식 일반적으로 무압축
PNG 투명도 지원, 원본 정보 보존에 유리 무손실
GIF 간단한 애니메이션 등에 사용 무손실
JPEG 사진 저장에 많이 사용 손실

BMP

픽셀 정보를 비교적 그대로 저장하기 때문에 파일 크기가 커질 수 있다.

PNG

무손실 압축을 사용하며 투명도를 지원한다.

GIF

색상 수에 제한이 있고 간단한 애니메이션을 표현하는 데 사용된다.

JPEG

사진처럼 색상과 명암이 복잡한 이미지에 적합하다. 손실 압축을 사용하기 때문에 파일 크기를 크게 줄일 수 있다.

시험 암기:

PNG → 무손실
GIF → 무손실
JPEG → 손실
BMP → 일반적으로 무압축

10. 소리 파일 형식

형식 특징 압축 방식
WAV 원본에 가까운 고품질 오디오 저장 일반적으로 비압축
FLAC 음질 손실 없이 용량을 줄임 무손실
MP3 널리 사용되는 음악 파일 형식 손실
AAC 효율적인 손실 압축 오디오 형식 손실

WAV

압축하지 않거나 압축이 적은 형태로 저장되는 경우가 많아 파일 크기가 크다.

FLAC

압축을 해도 원래의 디지털 오디오 데이터를 정확하게 복원할 수 있다.

MP3

사람이 듣기에 상대적으로 덜 중요한 정보를 제거하는 손실 압축을 이용한다.

AAC

MP3와 마찬가지로 손실 압축을 사용하지만 높은 압축 효율을 목표로 만들어진 형식이다.

시험 암기:

WAV → 비압축 계열
FLAC → 무손실
MP3 → 손실
AAC → 손실

11. 암호화

암호화는 데이터를 다른 사람이 쉽게 이해하지 못하도록 특정한 규칙에 따라 변환하는 것이다.

원래 데이터를 평문, 암호화된 데이터를 암호문이라고 한다.

평문 ↓ 암호화 ↓ 암호문 ↓ 복호화 ↓ 평문

암호화와 압축의 차이

구분 목적
압축 데이터 크기를 줄임
암호화 데이터를 보호함
압축했다고 해서 보안이 되는 것은 아니다. 암호화했다고 해서 반드시 파일 크기가 작아지는 것도 아니다.

12. 치환형 암호

치환형 암호는 문자의 위치는 유지하면서 문자 자체를 다른 문자로 바꾸는 방식이다.

예시

알파벳을 다음과 같이 바꾼다고 해보자.

A → D B → E C → F D → G ...

그렇다면

ABC ↓ DEF

가 된다.

치환형 = 글자를 다른 글자로 바꾼다.

중요한 특징

  • 문자의 위치는 기본적으로 유지된다.
  • 문자를 다른 문자로 바꾼다.
  • 대표적인 예로 시저 암호를 생각할 수 있다.

13. 전치형 암호

전치형 암호는 문자를 다른 문자로 바꾸는 것이 아니라 문자의 위치를 바꾸는 방식이다.

예시

원문: ABCDE 전치: CADBE

문자 자체는 그대로 A, B, C, D, E이지만 순서가 바뀌었다.

전치형 = 글자는 그대로, 위치를 바꾼다.

치환형과 비교

구분 치환형 전치형
문자 자체 바뀜 그대로
위치 기본적으로 유지 바뀜
핵심 문자를 다른 문자로 교체 문자의 순서를 변경
초간단 암기:

치환 = 다른 문자로 바꿈
전치 = 자리만 바꿈
